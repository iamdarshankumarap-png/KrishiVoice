# 🌱 KrishiVoice – AI Farming Assistant

KrishiVoice is an AI-powered multilingual farming assistant designed to help farmers get instant answers to agricultural questions through voice and text interactions.

## 🚀 Features

- 🎤 Voice-based interaction
- 🤖 AI-powered agricultural question answering
- 🌍 Multilingual support – English, Kannada and Hinglish
- 🔊 Text-to-Speech (TTS)
- 📝 Speech-to-Text (STT)
- 🌾 Practical agricultural guidance
- 💬 Interactive question-and-answer system

## 🛠️ Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- Gnani AI – Voice Integration
- AI / LLM API

## ⚙️ Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd KrishiVoice
   ```

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate it:

   ```bash
   venv\Scripts\activate
   ```

5. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

6. Configure the required API keys in your `.env` file.

7. Start the application:

   ```bash
   python app.py
   ```
